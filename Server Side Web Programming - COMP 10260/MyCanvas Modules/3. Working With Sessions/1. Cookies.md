Cookies are small pieces of data stored on the user's browser that allow web applications to remember user information and preferences across sessions. They play a vital role in enhancing user experience by personalizing content and maintaining user state.

```php
setcookie('username', 'john_doe', time() + 3600, '/', 'example.com', true, true);
```

### **Accessing Cookies**
Cookies set by the server are accessible using the `$_COOKIE` superglobal array.
For example, to retrieve the value of a cookie named "username": 
```php 
$username = $_COOKIE['username'];
```

### **Modifying Cookies**
To modify a cookie, simply set it again using the `setcookie()` function with updated values.

### **Deleting Cookies**
To delete a cookie, set its expiration time to a value in the past using the `setcookie()` function.
```php
setcookie('username', 'john_doe', time() - 3600);
```
