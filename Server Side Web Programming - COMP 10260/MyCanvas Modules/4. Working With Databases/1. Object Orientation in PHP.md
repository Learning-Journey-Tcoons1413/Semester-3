You have been instructed in Object  Oriented Programming in your Java course, and what you've learned there will transfer to PHP. This course does not require you to use custom classes, but you might find it helpful, and you are welcome to use these techniques in your solutions.

The reason we put a primer to OOP here is that we will use an object oriented API (application programming interface) to access databases. The features of abstraction and encapsulation are put to great use in the database API.

Let's jump into a refresher:

Classes are blueprints of how to build objects. You write a description of what the class attributes and methods are but don't put them to work anywhere. As in Java, the variable `$this` is a reference to the current object. So, in a class it doesn't mean anything but once you make an instance, each object will have a different value based on where it is in memory.
```php
class A {  
   function foo() {  
      if (isset($this)) {  
         echo '$this is defined (';  
         echo get_class($this);  
         echo ")\n";  
      } else {  
         echo "\$this is not defined.\n";  
      }  
   }  
}  
```

Unless a class is static, you have to create an instance of a class to get a reference to an object using the new() function. The variables associated with your object (attributes!) are unique to your object but all the objects will share the functions (methods!) that are available in the class.
```php
$instance = new SimpleClass();  
  
// This can also be done with a variable:  
$className = 'SimpleClass';  
$instance = new $className(); // new SimpleClass()  
```

Constructors are a little different than in Java in that they are all called `__construct()`. PHP also supports a concept called destructors: this is a function that is called when the object is destroyed. They are all called `__destruct()`

class MyDestructableClass {  
   function __construct() {  
      print "In constructor\n";  
   }  
  
   function __destruct() {  
      print "Destroying " . __CLASS__ . "\n";  
   }  
}  
  
$obj = new MyDestructableClass();

One nuance that you may have already seen in earlier notes is that in order to "dereference", or look inside an object, you use the arrow operator instead of dot.

In Java you would type `object.attribute` or `object.method()`, but in PHP you will use `object->attribute` or `object->method()`. This is because "." is used for concatenation in PHP. It is very similar to notation from JavaScript in this regard.

Inheritance uses the extends keyword just as you have seen in Java. The Java `super` keyword is called `parent` in PHP.

[A simple exampleLinks to an external site.](https://stackoverflow.com/a/13835545/759749):

```php
<?php
class BaseClass {
   function __construct() {
       print "In BaseClass constructor\n";
   }
}

class SubClass extends BaseClass {
   function __construct() {
       parent::__construct(); // this will call your parent constructor
       print "In SubClass constructor\n";
   }
}

$obj = new BaseClass();
$obj = new SubClass();
?>
```

Public, private, and protected work as you have seen in Java, as are concepts such as abstract classes, etc.
