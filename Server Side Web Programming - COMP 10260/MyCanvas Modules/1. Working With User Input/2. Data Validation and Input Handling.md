
Recall: GET parameters are sent to the server as part of the URL. This URL, **http://localhost/myfolder/nextpage.php?streetnumber=88&streetname=Elm**, contains two GET parameters named streetnumber and streetname. To access the streetnumber parameter, we would include the following code in our program:

```php
$streetnum = filter_input(INPUT_GET, "streetnumber", FILTER_VALIDATE_INT);
$streetnum = filter_input(INPUT_POST, "streetnumber", FILTER_VALIDATE_INT);
```

### Example: Receiving Strings

Using the same URL from the previous example (**http://localhost/myfolder/nextpage.php?streetnumber=88&streetname=Elm**), to receive the streetname parameter from the URL above, we would include the following code in our program:

```php
$streetname = filter_input(INPUT_GET, "streetname", FILTER_SANITIZE_SPECIAL_CHARS);
```

### Other Common Filters

If you are receiving numbers or special strings, use a validate filter. Here are some options:
```php
FILTER_VALIDATE_INT FILTER_VALIDATE_FLOAT  
FILTER_VALIDATE_EMAIL FILTER_VALIDATE_URL
```

These validate filters will return null if the parameter is not found, false if it’s not formatted correctly, or a value of the appropriate type otherwise.

  
If you’re receiving normal string data, you should use a sanitize filter:
```php
FILTER_SANITIZE_SPECIAL_CHARS
FILTER_SANITIZE_EMAIL
```
