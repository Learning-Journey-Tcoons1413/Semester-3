### Creating, Opening, Writing to, Reading from, and Closing Text Files in PHP

#### Creating and Opening Files

In order to read or write with a file, it must be opened. [fopen()Links to an external site.](https://www.php.net/manual/en/function.fopen.php) is used to open or create a text file in various modes.

The syntax is:

```php
fopen( string $filename, string $mode, bool $use_include_path = false, ?resource $context = null ): resource|false
```

Example: File Open
 ```php
 $namesFile = fopen( 'names.txt', 'r' );
 ```

Example: File Write
```php
$writeResult = fwrite( $namesFile, 'Rasmus' );
```

Example: File Read
```php
$data = fgets( $namesFile );
```

### Creating a Text File Example
```php
$fileName = "example.txt";  
$file = fopen($fileName, "w"); // Open for writing  
  
if ($file) {  
    $content = "Hello, this is a sample text.";  
    fwrite($file, $content); // Write content  
    fclose($file); // Close the file  
    echo "File created and written successfully.";  
} else {  
    echo "Failed to open the file.";  
}  
```

### Reading a Text File Example
```php
$fileName = "example.txt";  
$file = fopen($fileName, "r"); // Open for reading  
  
if ($file) {  
    while (!feof($file)) {  
        $line = fgets($file);  
        echo $line . "<br>";  
    }  
    fclose($file); // Close the file  
} else {  
    echo "Failed to open the file.";  
}  
```
