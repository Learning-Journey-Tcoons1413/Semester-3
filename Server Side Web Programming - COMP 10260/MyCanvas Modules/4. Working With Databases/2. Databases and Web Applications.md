MySQL, MariaDB, Microsoft SQL Server, PostgreSQL, MongoDB, and IBM DB2 are examples of Database Management Systems (DBMS) - each of these systems implement the SQL language in slightly different ways. These are all examples of relational databases - databases that are organized in tables and relationships between the tables. Non-relational databases, such as a large JSON file, are sometimes accessed by "NoSQL" - "Not Only SQL". In this course we will deal with relational databases. With these different database servers available it makes sense that we want to encapsulate our interfaces with objects.

#### Important SQL Commands

The four basic operations on the rows of a table are INSERT (sometimes called CREATE), SELECT (sometimes called RETRIEVE), UPDATE and DELETE. This gives us the acronym "CRUD" for the operations we commonly use on databases.

![[Pasted image 20241122181855.png]]

- SELECT field... FROM table [WHERE condition] [ORDER BY field [DESC] ...] [LIMIT n]
    - SELECT * gets you all the fields
- Examples:
    - `SELECT * FROM people;` is the same as `SELECT names, age FROM people;` (note the SQL is not case sensitive)
    - `SELECT names FROM people WHERE age > 25;`
- INSERT INTO table (column...) VALUES (value...), string values must be quoted using single quote
    - Example: INSERT INTO people (names,age) VALUES ('Ip Man',127);
- UPDATE table SET field=value... [WHERE condition]
    - UPDATE people SET age = 20 WHERE age < 35;
    - You can do arithmetic using field names.
        - Example: UPDATE table SET field1=field2+field3 WHERE field4 > 10
- DELETE FROM table [WHERE condition]  
    - Example: DELETE people WHERE age = 20;

#### **Issuing SQL Queries**

After you've established a database connection there are 3 steps to follow, regardless of whether you're performing INSERT, UPDATE, or DELETE.

1. Prepare your SQL statement
2. Execute the statement
3. Check for execution errors

There are two methods of identifying values to be substituted: a ? character or :_name_, where _name_ is chosen by us. 

###### Positional Parameters: Array
```php
$command = "INSERT into grades (firstname, lastname) VALUES (?, ?)";  
$stmt = $dbh->prepare($command);  
$success = $stmt->execute(["Drizzt", "Do'Urden"]);  
```

###### Named Parameters: Associative Array (Any Order)
```php
$command = 'SELECT name, colour, calories FROM fruit WHERE calories < :calories AND colour = :colour';  
$stmt = $dbh->prepare($command);  
$success = $stmt->execute(['colour' => 'red', 'calories' => 150]);
```

###### FETCH_ASSOC, FETCH_BOTH, FETCH_OBJ
```php
   $sth = $dbh->prepare("SELECT name, colour FROM fruit");  
   $sth->execute();  
  
   /* Exercise PDOStatement::fetch styles */   print("PDO::FETCH_ASSOC: ");  
   print("Return next row as an array indexed by column name\n");  
   $result = $sth->fetch(PDO::FETCH_ASSOC);  
   print_r($result);  
   print("\n");  
  
   print("PDO::FETCH_BOTH: ");  
   print("Return next row as an array indexed by both column name and number\n");  
   $result = $sth->fetch(PDO::FETCH_BOTH);  
   print_r($result);  
   print("\n");  
  
   print("PDO::FETCH_OBJ: ");  
   // approximately the same as fetch_object()  
   print("Return next row as an anonymous object with column names as properties\n");  
   $result = $sth->fetch(PDO::FETCH_OBJ);  
   print $result->name;  
   print("\n");
```
