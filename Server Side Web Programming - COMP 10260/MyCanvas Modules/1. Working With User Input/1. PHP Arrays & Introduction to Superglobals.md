Arrays that use string index  values are called "associative arrays".  You can access individual elements through integer or string index values depending on whether you are using traditional or associative arrays. Note that PHP's weak type rules will apply to the values in the index, so floats will be cast to integer, etc.
```php
echo $a[0]; // shows red  
echo $b["name"]; // shows test  
echo $c[2.5]; // shows 55.7
```

You can iterate through numeric array elements just like you would in Java.
```php
for ($i = 0; $i < count($c); $i++) {
	echo $c[$i];
}
```

You can also use the special foreach loop with either type of array. It's very similar to Java’s enhanced for loop:
```php
foreach ($c as $element) {
	echo $element;
}
```

You can also see the index values with the foreach loop if you choose:
```php
foreach ($c as $key => $value ) {
	echo "The key is $key, and the value is $value.";
}
```

Just do this:
```php
echo "Hello, {$b["name"]}.\n"; // valid  
echo "Hello, {$b['name']}.\n"; // valid
```
#### **JSON Encoding in PHP**

JSON encoding is the process of converting a PHP array or object into a JSON string format. PHP provides the [`json_encode()`Links to an external site.](https://www.php.net/manual/en/function.json-encode.php) function to convert PHP data structures into JSON format.

In this example we convert the array and output it. What that looks like client side depends on if we just load the PHP file directly or if this is responding to an AJAX call:

```php
$data = array("name" => "John", "age" => 25);
```

#### **JSON Decoding in PHP:**

JSON decoding is the process of converting a JSON string back into a PHP array or object. This is useful when you receive JSON data from an external source - whether that's client side, a file, a database, or somewhere else! PHP offers the [`json_decode()`Links to an external site.](https://www.php.net/manual/en/function.json-decode.php) function to convert a JSON string into a PHP data structure.

Example:

```php
$jsonString = '{"name":"John","age":25}';
```

## [PHP Superglobal ArraysLinks to an external site.](https://www.php.net/manual/en/language.variables.superglobals)

PHP superglobal arrays are predefined associative arrays that provide access to various types of data related to the web server, user input, and application state. Superglobal arrays are accessible from any part of a PHP script, making them global in scope. They play a crucial role in handling user input, session management, and server-related information. PHP superglobal arrays are denoted by a leading underscore followed by uppercase letters (e.g., $_GET, $_POST, $_SESSION).

Commonly used PHP superglobal arrays include:

1. **[$_GET](https://www.php.net/manual/en/reserved.variables.get.php):** Contains data sent to the script via URL parameters in the HTTP GET method. It's used to retrieve data from URLs, like query strings.
    
2. **[$_POST](https://www.php.net/manual/en/reserved.variables.post.php):** Holds data submitted to the script via HTTP POST method, usually from HTML forms or AJAX function calls. It's used to handle form submissions and sensitive data.
    
3. **[$_REQUEST](https://www.php.net/manual/en/reserved.variables.request.php):** Contains both GET and POST data, as well as data from cookies. It's used to access data from various sources, but it's important to be cautious due to its inclusivity.
    
4. **[$_SERVER](https://www.php.net/manual/en/reserved.variables.server.php):** Holds information about the server environment, such as headers, paths, and script locations. It's used to access server-related data.
5. **[$_SESSION](https://www.php.net/manual/en/reserved.variables.session.php):** Stores session data for a user on the server. It's used to maintain user-specific information across multiple pages or visits.
    
6. **[$_COOKIE](https://www.php.net/manual/en/reserved.variables.cookies.php):** Contains data stored in cookies sent by the client's browser. Cookies are used for retaining user-specific information.
    
7. **[$_FILES](https://www.php.net/manual/en/reserved.variables.files.php):** Contains data about uploaded files via HTTP POST method. It's used to manage file uploads from forms.
    
8. **[$_ENV](https://www.php.net/manual/en/reserved.variables.environment.php):** Stores data related to environment variables. It's used to access system-related information.
